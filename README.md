# callory-tracker

Трекер калорий: дневник питания, учёт продуктов дома, подбор рецептов и встроенный ИИ-помощник.

Учебный проект на Next.js, TypeScript, Tailwind CSS и SQLite.

## Запуск

Нужен Node.js 24 или новее.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:3000. База данных создаётся автоматически в файле `data/app.db`, в git она не попадает.

## Ветки

- `main` — рабочие, проверенные версии.
- `dev` — текущая разработка.
